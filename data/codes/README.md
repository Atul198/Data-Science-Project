## Code Directory

This folder contains Python scripts used for data preprocessing, cleaning, and validation.

### Scripts
- **Cleandata_Gold_import_2019_2024.py**  
  Cleans and standardizes Comtrade gold import data (2019–2024), filters import records, constructs a monthly time index, and exports an analysis-ready dataset.

- **Missing_Values_Analysis_for_Gold.py**  
  Performs missing value analysis on the cleaned dataset and reports column-level and overall missing value statistics.

- **Swift_Rmb_tracker.py**  
  Cleans and validates SWIFT RMB Tracker data extracted from PDF reports and exports a structured CSV file.

All scripts are designed to ensure reproducibility and transparency of the data preparation process.
